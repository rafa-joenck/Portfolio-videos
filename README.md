How the videos were made

The work starts from reference documents in Word or PDF, converted to Markdown and organized in an AI-supported workflow to help create instructional training videos for Benner systems.

AI is one stage of the process. What it generates goes through my work on three fronts: data curation, caption and context review, and screen capture.

Como os vídeos foram desenvolvidos

O trabalho parte de documentos de referência em Word ou PDF, convertidos para Markdown e organizados em um fluxo com IA para apoiar a criação de vídeos didáticos de treinamento de sistemas Benner.

A IA é uma etapa do processo. O que ela gera passa pelo meu trabalho em três frentes: curadoria dos dados, revisão de legendas e contexto, e captura de tela.
